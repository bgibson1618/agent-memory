Context

Every session starts cold

Until now: Claude Code's built-in memory is per-project and Claude-only, plus chat history and scattered notes.

  • Knowledge learned in one session is lost to every other agent and project
  • No cross-agent access, no semantic recall, no concept graph
  • Brent is absorbing a flood of new concepts he wants working inside his AI workflow
Source: PRD §3 "What the User Does Today" and §2 persona. The real operator is the agents themselves — they save and search on Brent's behalf.

Shipped

One store, three ways to find it

An OKF markdown store is the source of truth. Three rebuildable indexes read it; one command fuses them.

  • Lexical — SQLite FTS5 keyword search
  • Semantic — vector recall via local Ollama embeddings
  • Graph — a derived wikilink/topic graph, traversed in-process
  • mem search fuses all three with RRF — a concept findable by only one leg still surfaces in the top results
Source: README "What this is" and FEATURES F6. The fuse-all property is test-proved with lexical-only, semantic-only, and graph-only fixtures. CLI surface: mem init / doctor / save / search / extract.

Save once, recall anywhere

The core promise, test-proved: from a fresh Claude session in a different project, a fused search returns a previously saved concept in the top results.

  • One capture command: mem save — body from stdin, committed to the KB's own git history
  • One retrieval command: mem search "anything" — ranked, agent-parseable, one screen by default
Source: PRD success criterion 1 and FEATURES F6/F2. Walk it live if there's time: mem save in this repo, mem search from another.

Point it at a document

/mem:extract mines a paper or spec for durable concepts, dedups them against the KB, saves what's new, and reports added vs. skipped.

  • Dedup threshold 0.79 — measured against real KB data, not guessed (Decision D3)
  • Closeout observation: a fresh session ran the full choreography unprompted on a new document — 7 concepts added, every KB commit verified real
  • Deliberately the only slash command — save and search stay ambient (Decision D6)
Source: PRD use case 4, DECISION_LOG D3/D6, BUILD_LOG closeout F10 re-observation (run architect-iqj1). One of the 7 saves was a disposition-review override at 0.8403 similarity — the threshold has a human-judgment seam.

How it holds up

Degraded, never broken

  • Ollama down → search still answers from lexical + graph, one warning line, exit 0
  • Saves land anyway — embeddings queue and the concept becomes semantically searchable when the daemon returns
  • Concurrent sessions write safely — proved with 10-way race tests
  • External edits to KB files (even meaning-flips) are detected and re-indexed
Source: README "Using it", FEATURES F6, and the IMPLEMENTATION.md evidence rows for F7 (10-way distinct-slug race) and F8 (meaning-flip semantic refresh). The theme: no failure mode takes the KB offline.

Shipped

Confidentiality enforced by machine, not policy

  • Zero egress, proved: every command runs inside a loopback-only network namespace in the test suite — a regression can never land silently
  • With Ollama up, the only network peer across all operations is the local Ollama endpoint — memory content never leaves the machine
  • The KB is a git repo with zero remotes, for life — mem doctor fails loudly if one ever appears
  • Recall is vendor-scoped: Claude and Codex only; Antigravity/Gemini agents are excluded from memory work entirely (Decision D1)
Source: FEATURES F12 and F1, README vendor-scope paragraph, DECISION_LOG D1. The netns guard covers subprocess egress (git) as well as Python's own sockets, across init/doctor/save/search/get/list/extract/reindex.
